자료 안내

데이터 갱신 방법

1) 엑셀 원본(data-source)을 수정합니다. 코드는 문자열로 유지하고(앞자리 0 보존), legacy_specs_raw.json은 건드리지 않습니다.
2) node tools/import.cjs — JSON·CSV·calcmap.js 재생성.
3) node tools/import.cjs --check — 재생성 결과 일치 확인.
4) node tools/test-explorer.cjs, node tools/run-calctests.cjs — 회귀 테스트.
5) node tools/serve.cjs — 로컬 프리뷰 후 push는 별도 지시에 따라.
